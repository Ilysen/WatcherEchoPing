# Watcher Echo Ping

A mod for [Rain World: The Watcher](https://store.steampowered.com/app/2857120/Rain_World_The_Watcher/) that causes a distinct visual and sound effect when loading a region that has an echo present, like Saint's campaign in Downpour. For more a thorough description including screenshots, check the [Steam Workshop page](https://steamcommunity.com/sharedfiles/filedetails/?id=3454341892).
